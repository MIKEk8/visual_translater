# 📚 Claude Code Work Directory

## Обзор директории /cc/

Директория `/cc/` предназначена для ведения логов работы Claude Code над проектом Screen Translator v3.0 (Rust + Tauri).

## 📁 Структура директорий (по мере необходимости)

### `/cc/tasks/` - Управление задачами
- **Дневные логи:** `YYYY-MM-DD.md` - выполненные задачи с временными метками
- **TODO списки:** `TODO_<topic>.md` - задачи по категориям

### `/cc/docs/` - Техническая документация
- Архитектурные решения
- Заметки по реализации
- Бизнес-логика

### `/cc/analysis/` - Анализ и метрики
- Результаты анализа кода
- Метрики качества
- Отчеты по рефакторингу

## 🔧 Использование

### Для Claude Code
```bash
# При работе с задачей - обновить лог
Write("/workspace/cc/tasks/2025-09-29.md",
      content="## [HH:MM] Задача - Описание")

# При нахождении проблемы - создать TODO
Write("/workspace/cc/tasks/TODO_new_issue.md",
      content="# TODO: Описание проблемы")

# При архитектурном решении - документировать
Write("/workspace/cc/docs/architecture_notes.md",
      content="# Архитектурное решение: ...")
```

## 📝 Правила

1. **Всегда** документировать важные архитектурные решения
2. **Создавать TODO файлы** для проблем, найденных при анализе
3. **Вести дневной лог** выполненных задач с временными метками
4. **Группировать информацию** по темам в отдельные файлы
5. **НЕ добавлять TODO** комментарии в код - использовать `/cc/tasks/`
